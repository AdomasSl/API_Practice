<h1 align="center" id="title">PokeAPI Location Fetcher (Practice Project)</h1>

<p id="description">This script is a practice project and my first attempt at working with a public API using Python. It connects to the PokeAPI retrieves a random set of five consecutive locations makes additional requests to gather extra details (such as the region each location belongs to) and saves the enriched data to a timestamped JSON file. The goal of this project is to practice API requests JSON handling basic data processing and file management in Python.</p>
